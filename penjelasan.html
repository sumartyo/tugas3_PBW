2. Folder js/components/ — 5 Komponen Vue

Setiap komponen didaftarkan dengan Vue.component('nama-kebab-case', { template: '#tpl-...', ... }). Template ditulis di index.html sebagai <template id="tpl-..."> agar sesuai instruksi tugas.

2.1 status-badge.js Conditional + Computed

Tujuan: Menampilkan badge status stok (Aman / Menipis / Kosong) berdasarkan perbandingan qty vs safety. 

Vue.component('status-badge', {
  template: '#tpl-badge',
  props: ['qty', 'safety'],
  computed: {
    status() {
      if (this.qty === 0)       return { label:'Kosong',  class:'badge-danger',  icon:'⛔' };
      if (this.qty < this.safety) return { label:'Menipis', class:'badge-warning', icon:'⚠️' };
      return { label:'Aman', class:'badge-success', icon:'✅' };
    }
  }
});

Poin kunci:

  • props → data diterima dari parent (one-way binding).
  • computed status → Indikator 3 (Conditional) dan Indikator 4 (Computed).
  • Kelas CSS dinamis (badge-danger/warning/success) → warna merah/oranye/hijau sesuai kaidah tugas. 
<template id="tpl-badge">
  <span :class="['badge', status.class]" :title="status.label">
    {{ status.icon }} {{ status.label }}
  </span>
</template>

2.2 app-modal.js Reusable + Conditional

Tujuan: Modal konfirmasi generik untuk hapus data stok. 

Vue.component('app-modal', {
  template: '#tpl-modal',
  data() { return { visible:false, message:'', onConfirm:null }; },
  methods: {
    open(message, onConfirm) { this.message=message; this.onConfirm=onConfirm; this.visible=true; },
    confirm() { if (this.onConfirm) this.onConfirm(); this.visible=false; },
    cancel()  { this.visible=false; }
  }
});

Poin kunci:

  • Dipanggil dari parent via this.$refs.modal.open(msg, callback).
  • v-if="visible" pada template → Indikator 3 (Conditional).
  • Reusable: bisa dipakai untuk konfirmasi apa pun, bukan hanya hapus stok.

2.3 stock-table.js Kompleks: Filter + Sort + CRUD

Tujuan: Menampilkan daftar stok, filter (UPBJJ, Kategori, Reorder), sort (judul/qty/harga), form tambah/edit dengan validasi, hapus via modal.

a. Data & props

props: ['items', 'upbjjList', 'kategoriList'],
data() {
  return {
    filterUpbjj:'', filterKategori:'', filterReorder:false,
    sortBy:'', sortDir:'asc',
    editMode:false, editItem:null,
    newItem: this.emptyItem(), errors:{}
  };
}

b. Computed: dependent options + filter + sort

computed: {
  showKategoriFilter() { return this.filterUpbjj !== ''; },
  filteredItems() {
    let r = this.items.slice();
    if (this.filterUpbjj) r = r.filter(i => i.upbjj === this.filterUpbjj);
    if (this.showKategoriFilter && this.filterKategori)
      r = r.filter(i => i.kategori === this.filterKategori);
    if (this.filterReorder)
      r = r.filter(i => i.qty < i.safety || i.qty === 0);
    if (this.sortBy) {
      r.sort((a,b) => {
        let va=a[this.sortBy], vb=b[this.sortBy];
        if (typeof va === 'string') { va=va.toLowerCase(); vb=vb.toLowerCase(); }
        return (va<vb?-1:va>vb?1:0) * (this.sortDir==='asc'?1:-1);
      });
    }
    return r;
  }
}

Poin kunci:

  • showKategoriFilter → dependent options (filter kategori baru muncul setelah UPBJJ dipilih) sesuai instruksi.
  • filteredItems → di-cache Vue, tidak recompute selama dependensi tidak berubah → memenuhi "tidak perlu recompute kembali".
  • v-for="item in filteredItems" → Indikator 6 (Array).

c. Watcher (2 buah)

watch: {
  filterUpbjj() { this.filterKategori = ''; },  // reset kategori saat UPBJJ berubah
  editMode()    { this.errors = {}; }            // reset error saat masuk/keluar edit
}

d. Methods: validasi + event handler

validate(item) {
  const e = {};
  if (!item.kode)      e.kode = 'Kode wajib';
  if (!item.judul)     e.judul = 'Judul wajib';
  if (!item.kategori)  e.kategori = 'Kategori wajib';
  if (!item.upbjj)     e.upbjj = 'UPBJJ wajib';
  if (!item.lokasiRak) e.lokasiRak = 'Lokasi rak wajib';
  if (item.harga <= 0) e.harga = 'Harga > 0';
  if (item.qty < 0)    e.qty = 'Qty >= 0';
  if (item.safety < 0) e.safety = 'Safety >= 0';
  this.errors = e;
  return Object.keys(e).length === 0;
},
submitNew()  { if (!this.validate(this.newItem)) return;
               this.$emit('add-item', { ...this.newItem });
               this.newItem = this.emptyItem(); },
startEdit(it){ this.editItem = { ...it }; this.editMode = true; },
submitEdit() { if (!this.validate(this.editItem)) return;
               this.$emit('update-item', { ...this.editItem });
               this.editMode = false; },
confirmDelete(it) {
  this.$refs.modalConfirm.open(`Hapus ${it.kode}?`,
    () => this.$emit('delete-item', it.kode));
}

Poin kunci:

  • @keyup.enter="submitNew" di template → simpan saat Enter ditekan ✅.
  • Validasi sederhana per field → Indikator 6 (form & event).
  • Komponen hanya $emit; parent (app.js) yang memutasi state → single source of truth.

2.4 do-tracking.js Search + Auto-generate DO

Tujuan: Pencarian DO/NIM, buat DO baru (auto-generate DO2025-001), tambah progress perjalanan. 

computed: {
  hasilPencarian() {
    if (!this.search) return this.data;
    const q = this.search.toLowerCase();
    return this.data.filter(d =>
      d.nomorDO.toLowerCase().includes(q) || d.nim.includes(q));
  },
  selectedPaketDetail() {
    return this.paketList.find(p => p.kode === this.newDO.paket) || null;
  }
},
watch: { 'newDO.paket'() { this.errors = {}; } },
methods: {
  generateDO() {
    const year = new Date().getFullYear();
    const seq  = String(this.data.length + 1).padStart(3, '0');
    return `DO${year}-${seq}`;   // DO2025-001, DO2025-002, ...
  },
  submitDO() {
    const e = {};
    if (!this.newDO.nim)      e.nim = 'NIM wajib';
    if (!this.newDO.nama)     e.nama = 'Nama wajib';
    if (!this.newDO.ekspedisi)e.ekspedisi = 'Ekspedisi wajib';
    if (!this.newDO.paket)    e.paket = 'Paket wajib';
    this.errors = e;
    if (Object.keys(e).length) return;
    const paket = this.paketList.find(p => p.kode === this.newDO.paket);
    this.$emit('add-tracking', {
      nomorDO: this.generateDO(),
      nim: this.newDO.nim, nama: this.newDO.nama,
      status: 'Dalam Perjalanan',
      ekspedisi: this.newDO.ekspedisi,
      tanggalKirim: this.newDO.tanggalKirim || new Date().toISOString().slice(0,10),
      paket: this.newDO.paket, total: paket.harga,
      perjalanan: [{ waktu: new Date().toLocaleString('id-ID'),
                     keterangan: 'DO dibuat' }]
    });
    this.newDO = { nim:'', nama:'', ekspedisi:'', paket:'', tanggalKirim:'' };
  }
}

Poin kunci:

  • @keyup.enter="onSearchEnter" dan @keyup.esc="clearSearch" → sesuai instruksi (Enter cari, Esc reset).
  • selectedPaketDetail + v-if di template → detail isi paket muncul setelah memilih paket.
  • Watcher newDO.paket → Indikator 5.
  • Format tanggal & harga pakai filter | currency dan method formatTanggal().

3. js/services/api.js — Data Service

Tujuan: Satu-satunya pintu masuk data (fetch JSON). Komponen tidak boleh fetch sendiri. 

const ApiService = {
  async fetchData() {
    try {
      const res = await fetch('data/dataBahanAjar.json');
      if (!res.ok) throw new Error(`Gagal memuat data: HTTP ${res.status}`);
      return await res.json();
    } catch (err) {
      console.error('[ApiService] Error:', err);
      return { upbjjList:[], kategoriList:[], pengirimanList:[],
               paket:[], stok:[], tracking:[] };  // fallback agar app tidak crash
    }
  }
};
Baris Penjelasan
const ApiService = { ... } Objek singleton; cukup satu instance global.
async fetchData() Mengembalikan Promise; dipanggil dengan await di app.js.
fetch('data/...json') Path relatif terhadap index.html. Wajib via server lokal (http://) — bukan file://.
if (!res.ok) throw ... fetch tidak otomatis throw saat HTTP error; harus cek manual.
await res.json() Parse body → objek JS.
catch + fallback Mencegah aplikasi blank putih; UI tetap render dengan state kosong.
Kenapa dipisah? Separation of Concerns — mudah diganti ke REST API nanti (cukup ubah URL di sini), mudah di-test (mock method), memenuhi indikator arsitektur folder services/.

4. js/app.js — Root Instance & Orkestrator

Tujuan: Mendaftarkan filter global, membuat root Vue, menyimpan state pusat, memuat data, menangani event dari komponen anak.

4.1 Global Filter

Vue.filter('currency', val => 'Rp ' + Number(val).toLocaleString('id-ID'));
Vue.filter('satuan',   val => val + ' buah');
Vue.filter('tanggal',  val => new Date(val).toLocaleDateString('id-ID',
  { day:'numeric', month:'long', year:'numeric' }));

Didaftarkan sebelum new Vue() karena template dikompilasi saat root dibuat. Memenuhi Indikator 7.

4.2 Data state global

data: {
  tab: 'stok',              // 'stok' | 'tracking' | 'order'
  loading: true,
  errorMessage: '',
  state: { stok:[], tracking:[], upbjjList:[], kategoriList:[],
           pengirimanList:[], paket:[] }
}

tab mengontrol v-show di index.html → routing sederhana tanpa vue-router (sesuai instruksi).

4.3 Lifecycle created()

async created() {
  try {
    const data = await ApiService.fetchData();
    this.state.upbjjList      = data.upbjjList      || [];
    this.state.kategoriList   = data.kategoriList   || [];
    this.state.pengirimanList = data.pengirimanList || [];
    this.state.paket          = data.paket          || [];
    this.state.stok           = data.stok           || [];
    this.state.tracking       = data.tracking       || [];
    this.loading = false;
  } catch (err) {
    this.errorMessage = 'Gagal memuat data: ' + err.message;
    this.loading = false;
  }
}

Kunci: created dipanggil sebelum mount (tidak butuh DOM) → data siap sebelum render pertama. || [] mencegah undefined masuk v-for.

4.4 Computed & Watcher

computed: {
  totalStok()     { return this.state.stok.reduce((s,x) => s + Number(x.qty||0), 0); },
  jumlahReorder() { return this.state.stok.filter(s => s.qty < s.safety || s.qty === 0).length; }

  loading(val) { if (!val && !this.state.stok.length) console.warn('Stok kosong'); },

Dua watcher → Indikator 5 (ditambah watcher di komponen = total > 2).

4.5 Methods: handler event dari komponen

methods: {
  handleAdd(item) {
    if (this.state.stok.some(s => s.kode === item.kode)) { alert('Kode sudah ada'); return; }
    this.state.stok.push(item);
  },
  handleUpdate(updated) {
    const i = this.state.stok.findIndex(s => s.kode === updated.kode);
    if (i > -1) this.$set(this.state.stok, i, updated);   // $set agar reaktif
  },
  handleDelete(kode) { this.state.stok = this.state.stok.filter(s => s.kode !== kode); },
  handleAddTracking(doBaru) { this.state.tracking.push(doBaru); },
  handleAddProgress({ nomorDO, waktu, keterangan }) {
    const d = this.state.tracking.find(t => t.nomorDO === nomorDO);
    if (d) { if (!Array.isArray(d.perjalanan)) this.$set(d, 'perjalanan', []);
             d.perjalanan.push({ waktu, keterangan }); }
  },
  handleNewDO(payload) {
    const year = new Date().getFullYear();
    const seq  = String(this.state.tracking.length + 1).padStart(3, '0');
    const paket = this.state.paket.find(p => p.kode === payload.paket);
    if (!paket) return;
    this.state.tracking.push({
      nomorDO: `DO${year}-${seq}`, nim: payload.nim, nama: payload.nama,
      status: 'Dalam Perjalanan', ekspedisi: payload.ekspedisi,
      tanggalKirim: new Date().toISOString().slice(0,10),
      paket: payload.paket, total: paket.harga,
      perjalanan: [{ waktu: new Date().toLocaleString('id-ID'), keterangan:'DO dibuat' }]
    });
    this.tab = 'tracking';
  }
}
Pola utama: komponen anak hanya $emit; root memutasi state. Ini single source of truth, komponen reusable, dan mudah di-test. $set dipakai saat mengganti elemen array berdasarkan indeks karena Vue 2 tidak mendeteksi arr[i] = x secara reaktif.

5. Alur Eksekusi & Pemenuhan Indikator

5.1 Alur dari load hingga interaksi

1. Browser buka index.html
2. Muat Vue → api.js → komponen → app.js (urutan penting!)
3. app.js: Vue.filter(...) daftar filter global
4. new Vue({ el:'#app' }) → data() dieksekusi (state kosong, loading=true)
5. created() → await ApiService.fetchData()
6. fetch('data/dataBahanAjar.json') → res.json() → objek JS
7. state.stok/tracking/dll terisi → loading=false → UI re-render
8. <ba-stock-table :items="state.stok"> terima props
9. User klik Enter di form → komponen $emit('add-item', item)
10. app.js handleAdd() → state.stok.push(item)
11. Vue reactivity → tabel update otomatis (tanpa reload)

5.2 Tabel pemenuhan indikator

Indikator Wujud Implementasi
1. Struktur & komponen Folder components/, services/; Vue.component() + <template id="tpl-...">
2. Menampilkan data {{ }} mustache, v-html untuk catatanHTML
3. Conditional v-if (filter kategori, modal, detail paket), v-show (tab), v-else di status badge
4. Data binding & property v-model filter/form, :class, :title; computed filteredItems, status, detailPaket
5. Watcher filterUpbjj, editMode (stock-table); newDO.paket (tracking); loading, tab (app.js)
6. Array v-for Daftar stok, perjalanan DO, opsi select — dengan :key
7. Filter formatting Vue.filter('currency'), 'satuan', 'tanggal'
8. Custom element & props <ba-stock-table>, <do-tracking>, <order-form>, <status-badge>, <app-modal>

5.3 Catatan penting saat demo video

  • Jalankan via server lokal: python -m http.server 8000 → buka http://localhost:8000.
  • Pastikan dataBahanAjar.json tidak punya duplikasi key DO2025-0001.
  • Urutan <script> di index.html: Vue → api.js → komponen → app.js (jangan dibalik).
  • Template #tpl-... harus ada di DOM sebelum script komponen dieksekusi.
